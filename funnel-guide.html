Funnel Builder & Leak Analysis

Edit stages · counts · deal size — watch conversion reflow live
Editable stage model Live conversion math Leak / drop-off focus 3 presets + auto-save

What it does: models any deal funnel as a set of editable stages — each with a deal count and an average deal size — and draws it as a tapered funnel. Conversion between stages is computed automatically, and a leak panel points at the single transition where you lose the most deals.

The point: before you can fix a leaky funnel you have to see it. This tool turns a stage model into a picture and a shortlist: which transition costs the most deals, and how much revenue it represents.

1 Getting started

Open funnel-dashboard.html in Chrome, Edge, or Firefox. No installation and no external libraries — it is fully self-contained and works offline.

The builder opens on the MPS pipeline preset: six stages from MQL / Inbound down to Won, pre-populated so every panel means something on first load. Switch presets with the chips in the top control bar, or start clean with Blank.

2 Layout at a glance

  • Top control bar — preset chips, the Show $ value toggle, and Reset / Print / Export JSON.
  • KPI row — six tiles: leads in, won, overall conversion, pipeline value, estimated won value, and the primary leak (the worst single transition).
  • Funnel view — the tapered funnel. Segment width is proportional to deal count; the % between two stages is the conversion for that transition.
  • Leak analysis — every transition ranked by drop-off, with the biggest loss highlighted and its bar shown at full width.
  • Editable stage model — the table you edit. Rename, set counts and deal sizes, reorder, or remove stages. Conversion and every KPI recompute instantly.

There is no “Apply” button — everything recalculates on every keystroke.

Tip: keep counts as whole numbers and deal sizes as millions (e.g. 0.8 = $800K). Counts of 0 are fine — the stage still renders at minimum width so you can see a fully-leaked stage.

4 How the numbers are computed

Three derived figures drive everything:

  • Conversion (stage → next): countnext ÷ countcurrent × 100. It is never entered by hand — it is a consequence of the counts.
  • Pipeline $M (per stage): count × avg deal $M. The Pipeline value KPI is the sum across all stages.
  • Estimated won value: won count × won avg deal $M — what the funnel is worth if it performs exactly as modeled.

Overall conversion is the bookend ratio: won ÷ leads in. The status coloring on the KPI tile is a rough guide: ≥15% strong, 8–15% typical for B2B, <8% worth a hard look at the top of the funnel.

What it does not do: this is a deterministic model, not a forecast. It has no time dimension and no Monte Carlo — it shows the shape of the funnel and the size of the leaks. For revenue forecasting with P50/P70/P90 bands, pair it with the Pipeline Forecast Dashboard.

5 Reading the leak analysis

Each row is one stage transition: from → to. The row shows how many deals were lost and the percentage drop; bar length is scaled to the worst transition, so the full-width bar is your primary leak.

DropColorRead as
≤ 25%GreenHealthy hand-off — little is lost here
25–40%AmberNormal leakage for a mid-funnel gate; monitor
> 40%RedA real leak — the fix should start here
Tip: leaks near the top (lead quality, qualification) and near the bottom (price, legal, champion) usually have different root causes. Fix the biggest absolute deal loss first — a 40% drop at $2M average is worth more than a 60% drop at $50K average.

7 Saving, resetting & exporting

  • Auto-save: every edit is written to your browser’s localStorage the moment you make it. Close the tab, come back later — your funnel is still there. A green ● auto-saved note confirms each change.
  • Reset: clears the saved model and restores the MPS pipeline preset. Only do this when you want to discard your edits.
  • Print: opens the print dialog with a clean, print-friendly render.
  • Export JSON: downloads funnel-snapshot.json with your stages — handy for versioning models alongside other pipeline artifacts.
Heads-up: the saved model lives in this browser only. Different computers or browsers will not share it — use Export JSON as your portable copy, and the presets as a fresh baseline.

8 Suggested workflow

  1. Shape it: load the closest preset (or blank) and enter your real stage counts. Keep stage definitions consistent with how your CRM classifies deals.
  2. Find the leak: look at the leak panel and the primary leak KPI — that transition is where the biggest number of deals disappear.
  3. Size the opportunity: note the pipeline value tied up above the leak and the estimated won value gain from moving conversion up even 5 points.
  4. Model a fix: raise the count on the stage after the leak to see the funnel re-shape and the won number climb.
  5. Export: snapshot the JSON and pair it with the forecast dashboard or playbook for the action plan.
