☁ Multi-device sync one catalog on every device

Data currently lives only in this browser. Sync stores a copy in your free Supabase project so desktop & phone stay in step — newest edit wins, and offline edits re-push when you're back online.
Not configured
Setup (5 min, free): 1) create a project at supabase.com · 2) open SQL Editor and run the SQL below, replacing YOUR_SECRET with the secret you type above · 3) paste the Project URL & anon key, tick Enable, then Save & test.
create table if not exists dashboard_sync (
  id text primary key,
  data jsonb,
  ts bigint,
  dev text
);
alter table dashboard_sync enable row level security;
drop policy if exists dash_app on dashboard_sync;
create policy dash_app on dashboard_sync for all
  using ((current_setting('request.headers', true)::json ->> 'x-app-secret') = 'YOUR_SECRET')
  with check ((current_setting('request.headers', true)::json ->> 'x-app-secret') = 'YOUR_SECRET');
grant all on dashboard_sync to anon, authenticated;
Every device uses the same Project URL, anon key, and secret — stored only in each device's own browser, never in this page.
